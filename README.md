# Personal Income & Expense Tracker [For Learning]
An Excel-based personal finance tracker designed to monitor monthly income, expenses, and savings throughout the year.

<img width="1806" height="902" alt="image" src="https://github.com/user-attachments/assets/87952c3f-0593-458c-a19d-2810a7060d7c" />

## Features

- Tracks multiple income sources, including salary, rent income, and freelance income
- Records expenses across categories such as housing, food, and transportation
- Automatically calculates monthly total income and expenses
- Calculates monthly savings based on income and expenses
- Provides Year-to-Date (YTD) totals
- Includes a monthly savings target for tracking financial goals
- Uses Excel Tables and structured references for organized data
- Keeps empty or zero-value periods clean using conditional formulas

## Excel Functions Used :

- `SUM()`
- `SUBTOTAL()`
- `IF()`
- Excel Tables
- Structured References
- Calculated Columns

## Main Calculation

`Savings = Total Income - Total Expenses`
